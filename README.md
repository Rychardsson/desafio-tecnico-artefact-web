# Desafio Técnico Artefact Web

Repositório destinado ao desafio técnico para desenvolvimento de uma aplicação web.

## Status

Este projeto está em fase inicial de configuração.

## Como começar

1. Clone o repositório:

   ```bash
   git clone https://github.com/Rychardsson/desafio-tecnico-artefact-web.git
   cd desafio-tecnico-artefact-web
   ```

2. Consulte as instruções específicas do projeto assim que a aplicação e suas dependências forem adicionadas.

## Contribuição

Crie uma branch para cada alteração, mantenha os commits objetivos e abra um pull request descrevendo as mudanças realizadas.
